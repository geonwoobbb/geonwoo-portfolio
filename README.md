# 최건우 · Security Portfolio

HTML, CSS, JavaScript로 제작한 반응형 정적 포트폴리오입니다.

## 로컬 실행

이 폴더에서 `python -m http.server 8080`을 실행하고 http://localhost:8080 을 여세요.

## Vercel

GitHub 저장소를 Import하고 Framework Preset은 Other, Root Directory는 저장소 루트, Build Command는 비워둡니다. 별도 패키지 설치나 빌드가 필요하지 않습니다.

## 수정

- 본문: index.html
- 디자인 및 모바일 레이아웃: style.css
- 이메일 복사: script.js
- 포트폴리오 PDF에서 추출한 이미지: assets/

공개 페이지에는 이메일 연락처를 사용하며 생년월일, 상세 주소, 휴대전화 번호와 원본 PDF는 포함하지 않았습니다.
